# Changelog

All notable changes to the Grounded RAG specification are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Note that the repository release version (`0.1.0`) is independent of the
specification's own version (`v1`).

## [Unreleased]

### Added

- Initial public release of the Grounded RAG v1 architecture specification:
  the constitution, proposal, v1 scope, eleven architecture decision records,
  three research-synthesis documents, and the technical and marketing
  whitepapers.
- Agent-facing repository structure: `AGENTS.md` (Tier-1 entry point),
  `CLAUDE.md`, and the Tier-2 guidance under `docs/agents/`.
- Contributor and CI infrastructure: issue and pull-request templates,
  sanitization and structural CI gates, Conventional Commits enforcement,
  a lefthook pre-commit hook, and a GitHub Pages deployment of the docs.
